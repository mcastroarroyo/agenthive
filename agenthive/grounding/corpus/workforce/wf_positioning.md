# Positioning: why Agent Workforce, and what it is not

Owner: Wursta Agent Workforce product team. Last reviewed 2026-11-01. Prototype documentation for the Wursta Agent Hive.

## Benefits for customers

| Benefit | What it means |
|---|---|
| Instant availability | Specialists are available on demand — no search, interviews or onboarding. |
| Predictable cost | The estimate is shown upfront, per job, before anything starts. |
| Brand consistency | Every deliverable follows the customer's fonts, colours, tone and writing rules. |
| Speed | Minutes, not days. |
| Quality control | Every deliverable passes QA review and fact-checking before delivery. |
| Format flexibility | Word, PowerPoint, Excel, PDF, CSV or Markdown. |
| No coding | Customers write a brief in plain English; they never build or configure agents. |

## A fourth tier in the AI-agent market

| Tier | Examples | What the customer gets |
|---|---|---|
| Enterprise infrastructure | Salesforce Agentforce, Microsoft Copilot Studio | Platforms to build and run agents inside a large software estate |
| Business builder platforms | Relevance AI, Taskade | Tools for business users to assemble their own agents and workflows |
| Developer frameworks | CrewAI, LangGraph, AutoGen | Code libraries to build multi-agent systems |
| **Commercial AI staffing marketplace — Agent Workforce** | — | **Finished, branded documents from hired specialists, paid per job** |

The first three tiers sell the means to build agents. Agent Workforce sells the finished work.

## Compared with hiring a freelancer

| | Freelancer marketplace | Agent Workforce |
|---|---|---|
| Finding the right person | Search, profiles, interviews | Pick a specialist by department |
| Price | Quoted per person, often after back-and-forth | Upfront estimate per job and priority tier |
| Brand | You explain your brand every time | Learned once, applied to every file |
| Turnaround | Days | Minutes |
| Quality | Depends on the person | QA review and fact-check on every deliverable |
| Revisions | Negotiated | Built-in revision workflow, new file version each time |

## What Agent Workforce is

- A document generation platform
- A specialist AI staffing service
- A branded deliverable factory
- A per-job service
- Google Cloud native

## What Agent Workforce is not

- **Not a general chatbot** — it delivers finished documents, not open-ended conversation.
- **Not a workflow automation tool** — it does not wire systems together or run triggers.
- **Not a replacement for Docs or Word** — it delivers files you open and edit in them.
- **Not a monthly subscription for end users** — customers pay per job (in the SaaS) or through their Gemini Enterprise subscription.
- **Not a design tool** — the Media department is experimental.
- **Not a platform for building custom agents** — customers hire specialists; they do not build them.

## How to talk about competitors

State categories and differences in what the customer receives (tools to build vs finished work). Do not make claims about another vendor's product features, prices or quality.
